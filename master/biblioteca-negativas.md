# Biblioteca de negativas da marca — Use Zero Hora

Negativas transversais, válidas para toda campanha da marca. Cada campanha
adiciona as suas em `01-kws.md`. Aplicar como lista compartilhada
`[UZH] Negativas — Marca` + `[UZH] Negativas — Jornal`.

## 1. Colisão com o jornal Zero Hora (GZH/RBS) — crítica

A marca colide com o jornal Zero Hora. Em campanhas **sem** KW de marca,
negativar em frase:

```
"jornal zero hora"
"zero hora noticias"
"zero hora rs"
"zero hora porto alegre"
"gzh"
"gauchazh"
"zero hora classificados"
"zero hora obituario"
"zero hora hoje"
"capa zero hora"
```

Em campanhas **com** KW de marca (`use zero hora` etc.), manter as
negativas acima — a entidade da marca é sempre "use zero hora" +
contexto surf/beachwear.

## 5. Marketplaces e canais que não convertem no site

Decisão por campanha: termos como `shopee`, `shein`, `mercado livre`,
`amazon` acompanhando a categoria indicam intenção de comprar no
marketplace. Negativar por padrão; reavaliar se a campanha tiver
racional para disputá-los.

```
shopee
shein
"mercado livre"
amazon
aliexpress
```
